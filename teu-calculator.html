How It Works

TEU (Twenty-foot Equivalent Unit) is a standard measurement used to express container capacity.

One 20ft container equals 1 TEU, while one 40ft container equals 2 TEU.

Formula:
Total TEU = 20ft containers + (40ft containers × 2)
